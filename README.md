# EjerciciosSwiftUI

Repositorio de ejercicios prácticos desarrollados con **Swift** y **SwiftUI** utilizando **Xcode**.

El objetivo de este proyecto es practicar los fundamentos del desarrollo de interfaces para aplicaciones Apple, aplicando componentes nativos de SwiftUI, manejo de estados, estructuras de datos y diseño de interfaces modernas.

## 🚀 Tecnologías utilizadas

* **Swift**
* **SwiftUI**
* **Xcode**
* **iOS**
* **Git / GitHub**

## 📚 Ejercicios

### Ejercicio 1

Ejercicio práctico orientado al desarrollo de una interfaz utilizando componentes de SwiftUI.

Conceptos trabajados:

* `View`
* `Text`
* `Image`
* `VStack`
* `HStack`
* `ZStack`
* Modificadores de SwiftUI
* Diseño y composición de interfaces

### Ejercicio 2

Ejercicio práctico enfocado en la construcción de una interfaz interactiva utilizando componentes de SwiftUI.

Conceptos trabajados:

* Componentes reutilizables
* Manejo de estado
* Interacción con elementos de la interfaz
* `Button`
* `@State`
* Layouts con SwiftUI
* Diseño de tarjetas y componentes visuales

## 🎯 Objetivos de aprendizaje

Este repositorio busca reforzar:

* Fundamentos del lenguaje Swift.
* Desarrollo de interfaces declarativas con SwiftUI.
* Organización y reutilización de componentes.
* Manejo de estados e interacción del usuario.
* Uso de Xcode para el desarrollo de aplicaciones Apple.
* Control de versiones utilizando Git y GitHub.

## ⚙️ Requisitos

Para ejecutar el proyecto se recomienda contar con:

* macOS
* Xcode
* Swift
* Un simulador de iOS o dispositivo Apple compatible

## ▶️ Ejecución

1. Clonar el repositorio:

```bash
git clone git@github.com:93Cast/EjerciciosSwiftUI.git
```

2. Entrar al proyecto:

```bash
cd EjerciciosSwiftUI
```

3. Abrir el proyecto en Xcode:

```bash
open EjerciciosSwiftUI.xcodeproj
```

4. Seleccionar un simulador de iOS o dispositivo compatible.
5. Ejecutar el proyecto utilizando **Run ▶** en Xcode.

## 🔄 Control de versiones
